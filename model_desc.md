The model was constructed as a hybrid bidirectional long short-term memory (BiLSTM) and Transformer network for residue-level prediction of post-translational modification (PTM) sites. Protein sequences were represented using a vocabulary of 27 tokens consisting of 22 amino-acid symbols and five special tokens denoting unknown residues, sequence start, sequence end, padding, and masking. A start token and an end token were appended to every sequence. The input length was fixed at 514 positions, corresponding to 512 amino-acid residues together with the two boundary tokens. Protein sequences longer than 512 residues were divided into 512-residue windows with a stride of 256 residues, giving 50% overlap between consecutive windows. Shorter sequences and incomplete terminal windows were padded to 514 positions. PTM annotations were mapped to their corresponding residue positions within each window.

Each token was first mapped to a trainable 128-dimensional embedding. The resulting sequence of residue embeddings was passed through a single bidirectional LSTM layer containing 64 hidden units in each direction. The forward and reverse LSTM outputs were concatenated at every sequence position, producing a 128-dimensional contextual representation for each residue. The BiLSTM therefore encoded the local sequence environment and sequence ordering from both directions while retaining a separate representation for every position in the protein segment.

The 128-dimensional BiLSTM representation was subsequently processed by three consecutive Transformer encoder layers. Each encoder layer contained an eight-head self-attention module followed by a position-wise feed-forward network. Within each attention layer, the 128-dimensional residue representation was separately projected into 128-dimensional query, key, and value representations. These projections were divided equally among the eight attention heads, resulting in a 16-dimensional representation per head. Each attention head independently determined the contribution of other residues within the sequence segment to the representation of a given residue. The outputs of the eight heads were concatenated to recover a 128-dimensional representation and passed through a 128-dimensional output projection.

Following self-attention, a dropout rate of 0.1 was applied before adding the attention output to the input representation through a residual connection. The resulting representation was normalized using layer normalization with an epsilon of 10^-6. It was then passed through the position-wise feed-forward network, which expanded the 128-dimensional representation to 512 features using a LeakyReLU activation and projected the result back to 128 dimensions. A second dropout layer with a rate of 0.1, residual connection, and layer-normalization operation completed each Transformer encoder block. The same 128-dimensional representation size was therefore maintained throughout all three Transformer layers.

The output of the third Transformer encoder was passed independently at every residue position through a fully connected layer containing 64 neurons with ReLU activation. This reduced the 128-dimensional contextual representation to a 64-dimensional PTM-specific feature representation. The 64-dimensional features were then passed to the final classification layer, which contained one sigmoid output for each PTM label included in the training set. The network consequently generated an independent PTM probability for every retained PTM class at every residue position.

Within the training set, model development used 15-fold cross-validation. The sequence records were distributed among the 15 folds while explicitly prioritizing the distribution of rare PTM classes across different validation folds. For each fold, one subset was used for validation and the remaining 14 subsets were used for training. A separate model was trained for each of the 15 folds. The three Transformer encoder layers in every fold used eight attention heads, a 512-unit feed-forward hidden representation, and a dropout rate of 0.1.
Each fold-specific network was initialized from the corresponding pretrained `MIND-S` model. The pretrained weights of the embedding layer, BiLSTM layer, and Transformer encoder layers were transferred to the new model and kept fixed during training. The 64-unit intermediate dense layer and final sigmoid classification layer were newly optimized for the PTM labels used in the present dataset.

Training used mini-batches of 64 sequence segments and the Adam optimizer with AMSGrad enabled and a learning rate of 0.001. A maximum of 200 training epochs was allowed for each fold. Training was terminated early when the training loss failed to improve for two consecutive epochs, and the weights corresponding to the lowest training loss were restored. The random seed was fixed at 252 for Python, NumPy, and TensorFlow to maintain reproducibility across model training.

The network was optimized using binary cross-entropy because each PTM output was treated independently. During training, negative sites were selected separately for each PTM class from residues of the appropriate amino-acid type. For a given PTM class within a training sequence, the number of sampled negative sites was matched to the number of available positive sites whenever sufficient negative candidates were present. This produced balanced positive and negative contributions for each PTM represented within a training segment.

After training the 15 models, predictions on the independent test set were combined into a fold ensemble. The contribution of each fold-specific model was calculated separately for each PTM class from that model's validation precision–recall area under the curve. The 15 validation PR-AUC values for a given PTM were normalized to sum to unity and were used as PTM-specific ensemble weights. The final prediction for each PTM was obtained by the corresponding weighted combination of predictions from all 15 fold-specific networks.
